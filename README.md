# TINYCUA

TINYCUA is a modular repository for agent-related subprojects.

The repository documentation and legacy implementation modules are being reset so
the project can rebuild its docs and application layers from a clean baseline.

## Subprojects

- `src/tinycua-sdk` — developer SDK
- `src/tinycua` — CLI/TUI application skeleton
- `src/tinycua-backend` — backend application skeleton
- `src/tinycua-finetune` — fine-tuning project and retained finetune specs

## Current documentation state

Historical docs have been removed. New cookbook-style documentation will be
added per project in future work.
