# Literature Review: Multi-Agent Systems and Task Decomposition

## Draft

Multi-agent systems (MAS) have demonstrated that decomposing complex tasks across specialized agents improves reliability and output quality. CAMEL (Li et al., 2023) was the first to show that autonomous cooperation among LLM agents is possible through role-playing and inception prompting, though it lacked task decomposition and context isolation. MetaGPT (Hong et al., 2023) advanced this paradigm by encoding Standardized Operating Procedures into an assembly line of specialized roles — Product Manager, Architect, Engineer, QA — working sequentially with intermediate verification. AutoGen (Wu et al., 2023) provided generic infrastructure for multi-agent conversation with flexible interaction patterns and human-in-the-loop capabilities. These systems validate structured orchestration but share a critical limitation: agents operate on shared context, with no mechanism to limit each agent's exposure to only the information relevant to its role.

TDAG (Wang et al., 2024) addresses this limitation by dynamically decomposing tasks into subtasks and generating specialized sub-agents for each, where each sub-agent receives only its subtask's context. This demonstrates that context isolation at the sub-agent level improves performance on complex tasks. However, TDAG's dynamic agent generation introduces computational overhead, produces unpredictable agent roles that are difficult to debug, and was validated only on large-scale models (GPT-4 class). TinyCUA draws from this multi-agent lineage but simplifies the approach: rather than dynamically spawning agents, it uses fixed staged processing nodes within a single agent boundary, achieving context isolation without the overhead and unpredictability of dynamic agent generation.
