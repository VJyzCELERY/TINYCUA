Conduct research on a specific topic.

**Research Directory**: $1
**Research Query**: $2

## Instructions

1. **Set Up Research Directory**: Create `$1/` directory and structure:
   ```
   $1/
   ├── research.md      # Main research document
   ├── index.md        # Research index
   └── presentation.md # Final presentation
   ```

2. **Understand the Request**: Analyze what needs to be researched
   - Break down the query into key topics
   - Identify research areas

3. **Conduct Research**: Use available tools:
   - Read existing project documentation
   - Use Web Search for external information
   - Analyze code and architecture

4. **Document Findings**: Create research.md with:
   - Executive summary
   - Key findings
   - References
   - Recommendations

5. **Create Index**: Maintain index.md with research progress

6. **Create Presentation**: Create presentation.md summarizing findings

## Constraints
- All research files MUST be written to `$1/**`
- You have read access everywhere but write access only in the research directory

Begin by setting up the directory and conducting research.
