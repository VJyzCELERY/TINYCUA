# Naming Conventions

This document defines the naming conventions for the MAIN-PROJECT-TEMPLATE and its subprojects.

## Subproject Naming Convention
1. Each subproject folder should be named using lower-kebab-case:
   - Example: `sub-project-name`
2. The corresponding source code (Python package) folder inside a subproject should use lower_snake_case:
   - Example: `sub_project_name`.

## File Naming Conventions
1. Python files:
   - Use snake_case.
   - Example: `my_module.py`
2. Test files:
   - Prepend with `test_`.
   - Example: `test_main.py`.
