     FeedForwardNetwork(ff_dim)  # Usually 4×d_model\n        \n    def forward(self, x):\n        # Residual connection
     + layer normalization at each sub-layer\n        attn_output = LayerNorm(x)(self.attention(LayerNorm(x)(x), \n
     LayerNorm(x)(x)))\n        ff_output = LayerNorm(attn_output)(self.feed_forward(\n
     LayerNorm(attn_output)(attn_output)))\n        \n        return x + ff_output  # Residual connection with encoder
     block\n\nclass Encoder(nn.Module):\n    def __init__(self, n_layers, ...):\n        self.layers =
     nn.Sequential(*[EncoderBlock(...) for _ in range(n_layers)])\n    \n    def forward(self, x):\n        return
     self.layers(x)\n```\n\n#### Decoder-Only Architecture (GPT-style)\nUsed primarily for **generating** sequences
     autoregressively. Uses causal masking to prevent attending to future tokens.\n\nKey differences:\n1. Causal
     attention mask prevents position i from seeing positions >i\n2. Adds cross-attention between encoder and decoder
     layers (in original architecture)\n3. Output projection maps final hidden state to vocabulary
     logits\n\n```python\nclass DecoderBlock(nn.Module):\n    def __init__(self, d_model, n_heads, ff_dim):\n
     self.self_attn = CausalMultiHeadAttention(d_model, n_heads)  # Masked!\n        self.cross_attn =
     CrossAttention(...)  # (Optional in decoder-only models)\n        self.feed_forward = FeedForwardNetwork(ff_dim)\n
     \n    def forward(self, x, encoder_output=None):\n        x = LayerNorm(x)(self.self_attn(LayerNorm(x)(x), \n
     LayerNorm(x)(x)))\n        if encoder_output is not None:  # Only in original architecture\n            cross_x =
     LayerNorm(cross_x)(self.cross_attn(\n                LayerNorm(x+cross_x)(x+cross_x),\n
     LayerNorm(encoder_output)(encoder_output)\n            ))\n        ff_input = x + (cross_x if encoder_output else
     0)\n        return LayerNorm(ff_input)(self.feed_forward(LayerNorm(ff_input)(ff_input)))\n\nclass
     Decoder(nn.Module):\n    def __init__(self, n_layers, ...):\n        self.layers =
     nn.Sequential(*[DecoderBlock(...) for _ in range(n_layers)])\n    \n    def forward(self, x,
     encoder_output=None):\n        return self.layers(x, encoder_output)\n```\n\n#### Original vs Modern
     Architectures\n\n**Original Transformer (2017):** Encoder-decoder with cross-attention between layers. Used for
     machine translation where source and target sequences have different lengths.\n\n**Modern Decoder-Only Models (GPT
     family):** Only decoder architecture without explicit encoding stage. The model learns to encode context through
     autoregressive training, making it suitable for both generation tasks and fine-tuning on classification/regression
     with appropriate output heads.\n\n### 3.4 Positional Encoding\n\nTransformers lack recurrence or convolution —
     there's no inherent notion of sequence order in the attention mechanism alone. To preserve positional
     information:\n\n#### Absolute Positional Embeddings\nAdd learned position vectors to token embeddings before
     processing:\n```python\n# X: N × D (token embeddings)\nPE = learnable_position_encoding(N, D)  # Each row is a
     unique position vector\nX_with_pos = X + PE                      # Element-wise addition\n\n# Why add instead of
     concat? Addition allows the model to learn relative positions easier.\n```\n\n**Sine/Cosine Positional Encoding
     (Original Transformer):**\nUses fixed sinusoidal functions so each dimension encodes different
     frequencies:\n```python\ndef get_sinusoidal_encoding(max_len, dim):\n    # Even dimensions: sin(position /
     10000^(2i/dim))\n    # Odd dimensions: cos(position / 10000^((2i+1)/dim))\n    # This allows model to learn
     relative positions as linear combinations of absolute ones!\n```\n\n**Why this matters:** Sinusoidal encoding has
     the property that `PE(pos + k) = PE(pos) + offset`, enabling the model to generalize to sequence lengths beyond
     training.\n\n### 3.5 Multi-Head Attention\n\nInstead of computing attention once with a single projection,
     multi-head attention performs multiple parallel attention computations on different subspaces:\n\n```python\nclass
     MultiHeadAttention(nn.Module):\n    def __init__(self, d_model, n_heads):\n        self.n_heads = n_heads\n
     dim_per_head = d_model // n_heads\n        \n        # Split input into Q/K/V projections for each head
     independently\n        self.W_Q = nn.Linear(d_model, d_model)  # Shape: D × (n_heads × d_k)\n        self.W_K =
     nn.Linear(d_model, d_model)  \n        self.W_V = nn.Linear(d_model, d_model)\n        \n    def forward(self, Q,
     K=None, V=None):\n        if K is None and V is None:  # Self-attention case\n            K, V = Q, Q\n        \n
     n_heads = len(Q.shape[:-1])   # Batch dimensions (batch_size × seq_len)\n        batch_size, seq_len =
     *Q.shape[:2], ...\n        \n        # Project to query/key/value spaces\n        q = self.W_Q(Q).view(batch_size,
     -1, n_heads, d_model // n_heads).transpose(1, 2)\n        k = self.W_K(K).view(batch_size, -1, n_heads, d_model //
     n_heads).transpose(1, 2)\n        v = self.W_V(V).view(batch_size, -1, n_heads, d_model // n_heads).transpose(1,
     2)\n        \n        # Compute scaled dot-product attention for each head independently\n        scores = q @
     k.transpose(-2, -1) / sqrt(dim_per_head)\n        attn_weights = softmax(scores, dim=-1)  # Shape: B × N_H × L ×
     L\n        \n        # Apply attention to values and recombine heads\n        out = (attn_weights @ v).transpose(1,
     2).contiguous()\n        \n        return out.view(batch_size, -1, d_model)  # Reshape back to D
     dimension\n```\n\n**Benefits of Multiple Heads:**\n- Different heads can specialize in attending to different types
     of relationships (syntax vs semantics)\n- Increases model capacity without increasing parameter count
     proportionally\n- Empirically found to improve performance on language modeling tasks significantly\n\n### 3.6
     Modern Variants: BERT, GPT, ViT\n\n#### BERT (Bidirectional Encoder Representations from
     Transformers)\n**Architecture:** Encoder-only transformer with bidirectional context  \n**Training
     objectives:**\n1. **Masked Language Modeling (MLM):** Predict randomly masked tokens using surrounding context\n2.
     **Next Sentence Prediction (NSP):** Predict whether two sentences appear consecutively\n\n**Use cases:** Question

     \n**Training objective:** Predict next token autoregressively (`x_{t+1} = f(x_1,...,x_t)`)\n\n**Fine-tuning

     ViT treats an image as a sequence of patches:\n```python\nclass ViT(nn.Module):\n    def __init__(self,
     img_size=224, patch_size=16, n_classes=1000):\n        # Split 224×224 into (224/16)² = 196 patches of 16×16 pixels
     each\n        self.patch_embed = nn.Conv2d(3, d_model, kernel_size=(patch_size, patch_size), \n
     stride=patch_size)  # Projects image to N × D\n        \n        self.pos_embeddings =
     learnable_position_encoding(N_patches + 1, d_model)  \n                                                # (+1 for
     class token [CLS])\n        \n        transformer_encoder = TransformerEncoder(n_layers=n_layers, ...)\n    \n
     def forward(self, x):\n        B = len(x)\n        x = self.patch_embed(x).flatten(2)     # Shape: B × N_patches ×
     D\n        cls_tokens = repeat(torch.randn(B, 1, d_model), 'b 1 d -> b n d', \n
     n=self.pos_embeddings.shape[0] - 1)  # Class token\n        x = torch.cat([cls_tokens, x], dim=1) +
     self.pos_embeddings  \n        \n        return transformer_encoder(x).squeeze(1)[..., :-1].mean()  # Pool via
     [CLS] or global avg\n```\n\n---\n\n## Part III: Practical Considerations\n\n### 4.1 Hyperparameters to Tune\n\n####
     Learning Rate Schedule\n| Strategy | Description | Best For |\n|----------|-------------|----------|\n| **Constant
     LR** | Same learning rate throughout training | Simple tasks, stable optimization landscape |\n| **Step Decay** |
     Reduce LR by factor every N epochs (e.g., reduce 10× after epoch 30) | Tasks with clear convergence patterns |\n|
     **Cosine Annealing** | Gradually decay from max to min following cosine curve | Fine-tuning pre-trained models,
     avoiding local minima |\n| **Warmup + Decay** | Start slowly then follow cosine or step schedule | Large batch
     sizes, preventing early divergence |\n\n#### Batch Size Considerations\n- Larger batches → faster training (better
     GPU utilization) but can converge to sharper minima (lower generalization)\n- Smaller batches → noisier gradients
     often generalize better (SGD benefit)\n- **Batch Normalization** helps stabilize larger batches by normalizing

     co-adaptation | 0.3–0.5 for hidden layers, less for early/layers near input/output |\n| **Weight Decay (L2)** |

     vanishing/exploding gradients\n- **Symptoms:** Loss plateaus early; weights don't change much during training\n-
     **Solutions:** \n  - Use activation functions with bounded derivatives (ReLU, Leaky ReLU instead of sigmoid/tanh)\n
     - Apply Layer Normalization or Batch Normalization to stabilize activations\n  - Clip gradients if using deep
     recurrent networks\n\n#### Problem: Overfitting\n- **Symptoms:** Training loss decreases but validation loss
     increases\n- **Solutions:** \n  - Add dropout layers in hidden layers (30–50% typical)\n  - Reduce model capacity
     (fewer parameters/layers)\n  - Increase training data or use augmentation techniques\n  - Apply weight decay
     regularization\n\n#### Problem: Underfitting  \n- **Symptoms:** Both train and validation loss remain high even
     after many epochs\n- **Solutions:** \n  - Increase model complexity (more layers/units per layer)\n  - Use longer
     training time with patience scheduling\n  - Try different initialization schemes (Kaiming for ReLU networks, Xavier
     for sigmoid/tanh)\n\n#### Problem: Poor convergence despite correct architecture\n- Check that learning rate is not

+## Part I: Fundamentals of Neural Networks
+
+### 2.1 What is a Neural Network?
+
+A neural network is a computational model inspired by biological neurons, consisting of interconnected nodes (neurons) organized in layers that learn patterns from data through iterative training.
+
+**Basic Structure:**
+```
+Input Layer → Hidden Layers (with non-linear activations) → Output Layer
+```
+
+The "deep" in deep learning refers to having many hidden layers between input and output.
+
+### 2.2 Core Components
+
+#### Neuron (Perceptron)
+A single neuron computes a weighted sum of inputs plus bias, then applies an activation function:
+
+```
+z = Σ(w_i * x_i) + b    # Weighted sum
+a = f(z)                # Activation applied to result
+```
+
+Where:
+- `w_i` = weight for input i
+- `x_i` = value of input i  
+- `b` = bias term (learnable offset)
+- `f()` = activation function
+- `a` = neuron's output/activation
+
+#### Layers and Weights
+```
+┌───────── Input Layer ────────┐
+│   x1    x2     ...    xn     │  ← Inputs/features
+└──────────────────────────────┘
+          ↓ [weights w, bias b]
+┌───────── Hidden Layer 1 ──────┐
+│   h1 = f(w·x + b)            │  ← First hidden unit
+│   ...                        │
+│   hm = f(Σw_j*xj + bm)       │  ← m units total
