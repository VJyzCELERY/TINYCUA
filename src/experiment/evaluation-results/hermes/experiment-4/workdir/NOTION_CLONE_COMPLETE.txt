- Monaco Editor (VS Code's code editor engine)


================================================================================
   QUICK START GUIDE - RUN THE APPLICATION NOW!
================================================================================

STEP 1: Install Dependencies
----------------------------
pip install -r requirements.txt


STEP 2: Initialize Database  
----------------------------
python app/init_db.py


STEP 3: Start the Server
-------------------------
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

OR run with bash script (if you have a shell):
bash start.sh


OPEN YOUR BROWSER AND VISIT: http://localhost:8000

================================================================================
   API ENDPOINTS AVAILABLE
================================================================================

Pages API:
POST /api/pages/              - Create new page  
GET  /api/pages/{page_id}     - Get specific page with blocks
GET  /api/pages/              - List all pages (optional filter by user)

Blocks API:
POST /api/blocks/             - Add/edit content block


Databases API:
POST /api/databases/          - Create new database/table  
GET  /api/databases/{db_id}   - Get database schema and entries

Auth API:
POST /api/auth/login          - Login endpoint (placeholder for JWT)
