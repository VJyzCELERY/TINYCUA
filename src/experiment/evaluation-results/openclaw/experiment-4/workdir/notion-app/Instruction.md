# 🚀 How to Run Your Notion Clone

## Step 1: Install Dependencies

Open a terminal and navigate to the app directory:

```bash
cd /workspace/experiment-4/notion-app
```

Install required Python packages:

```bash
pip install flask flask-cors
```

## Step 2: Run the Application

Start the Flask backend server:

```bash
python backend/app.py
```

You should see output like:
```
✓ Database initialized successfully!
 * Running on http://0.0.0.0:5000
```

## Step 3: Open in Browser

Open your web browser and go to:

**http://localhost:5000**

You'll see the login screen.
Enter any email address (e.g., `user@example.com`) and click "Continue"!

## 🎉 That's it! You're ready to use Notion Clone!

### What you can do now:
- ✅ Create new pages by clicking "+ New Page"
- ✅ Type content directly - everything is editable!
- ✅ Add headings (H1, H2, H3), paragraphs, lists
- ✅ Organize your workspace with sidebar navigation
- ✅ Use emoji icons on pages (📝 📊 🗂️ etc.)

### Tips:
- Just start typing - the editor is very intuitive!
- Press `Enter` to create new blocks/paragraphs
- Select text and press `Tab` for blockquotes
- The sidebar shows all your pages
- Click any page in the sidebar to navigate between them

Enjoy building with Notion Clone! 🎨
