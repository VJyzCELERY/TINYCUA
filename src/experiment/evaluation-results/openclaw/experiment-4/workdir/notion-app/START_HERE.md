# 🎉 Welcome to Notion Clone!

You've just built a lightweight, intuitive **Notion-like web app** using:
- ✅ Python Flask backend
- ✅ SQLite database storage
- ✅ Modern HTML/CSS/JavaScript frontend

## What You Have Now

Your application is ready at: `/workspace/experiment-4/notion-app`

### To Start Using It:

```bash
cd /workspace/experiment-4/notion-app
pip install flask flask-cors click python-dotenv
python backend/app.py
```

Then open **http://localhost:5000** in your browser!

## 🚀 Quick Demo Flow

1. Run: `python backend/app.py`

3. Enter email: `demo@example.com` → Click "Continue"

## 💡 Tips for Using the App

- Just click "+ New Page" to create new pages
- Type naturally - press Enter for new blocks/paragraphs
- Select text and hit Tab for blockquotes (>)
- Use emoji icons like 📝, 🗂️, 📊 in page titles
- The sidebar shows all your root-level pages
- Click any page to edit it!
